1. Right-click in Steam on any link and choose “Open link in new tab”

2. Paste this link in adress url; https://chromewebstore.google.com/

3. Pick any useless extension, later we will delete this. It will ask you to download extenstion file which you can save anywhere on your computer.

4. Extension will open in new window, go here - chrome://extensions/ and delete that 'useless' extension, top right turn on developer mode, Load unpacked and choose folder [CS2STATSEXT] and turn that on.
